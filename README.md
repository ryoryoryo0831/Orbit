# Orbit（動画・音楽プレイヤー）

VLC for Android の代わりに、家族で使うための動画・音楽プレイヤーです。ストアには公開していません。

| フォルダ | 中身 |
|---|---|
| `android/` | Android 版（Kotlin ＋ libVLC：VLC と同じ再生エンジン）。スマホ・タブレット・Android TV / Fire TV |
| `ios/` | iPhone 版（SwiftUI ＋ MobileVLCKit）。開発は保留中 |
| `docs/` | 引き継ぎメモ（`引き継ぎ.md`）、これまでの記録、iPhone 版のインストール手順 |
| `.github/workflows/` | ビルドと公開（GitHub Actions） |
| `index.html` | 最初に作ったブラウザ版の試作（ダブルクリックで開くだけで使えます。今は手を入れていません） |

## Android 版のインストール

1. このリポジトリの **Releases** を開きます。
   - **Latest**（緑の印）：みんなに配っている版です。ふつうはこれを入れます。
   - **Pre-release**：お試し版です。
2. スマホ・タブレットは `Orbit-1.0.N.apk`、テレビ（32 ビットの端末）は `Orbit-1.0.N-32bit.apk` をダウンロードします。
3. 「提供元不明のアプリ」のインストールを許可して、上書きインストールします。

入れたあとは、新しい版が出るとアプリが知らせてくれます（設定「新しい版を知らせる」）。

## Android 版の主な機能

- **再生**：libVLC で MKV・AVI・WMV・FLV・MPEG-2 など、AC3・DTS 音声、ASS 字幕まで。DVD の ISO（メニューの操作・本編の自動選択）、日本語の音声があれば自動で日本語に。
- **一覧**：動画・音楽・フォルダ・履歴・プレイリストのタブ。検索・並べ替え・グリッド表示、サムネイル、お気に入り、続きから再生。
- **再生画面**：ジェスチャー（明るさ・音量・シーク・ダブルタップ・長押しで 2 倍速・ピンチで拡大）、A-B リピート、速度、チャプター、スクリーンショット、音量ブースト、シーク中のプレビュー。
- **小窓**：ほかのアプリの上に重ねる自由な小窓（大きさ・場所を変えられる、端にしまえる）と OS の小窓。
- **音楽**：バックグラウンド再生、通知・ロック画面・イヤホンでの操作、ジャケット、再生キューの編集、イコライザー、スリープタイマー。
- **ネットワーク**：NAS（SMB）・FTP・SFTP・NFS・DLNA・URL、フォルダごとの再生、Chromecast へのキャスト。パスワードは暗号化して保存。
- **テレビ**：リモコン操作、大きめの文字、テレビ向けの初期設定。タブレットでは左に縦のタブ。
- **そのほか**：テーマ（暗い・明るい・端末に合わせる）、データの書き出し・読み込み、新しい版の知らせ、困ったときの「再生の記録」「落ちたときの記録」。

## 作る人向け

ビルドはすべて GitHub Actions で行います（ローカルに Android SDK は不要）。作業用ブランチへの push でビルドとテスト、main に入るとお試し版として公開されます。詳しい流れと決まりは [`docs/引き継ぎ.md`](docs/引き継ぎ.md) を見てください。
